# 배선 · 하드웨어 브링업 가이드

Arduino UNO Q에 센서·부저를 연결하고, 코드가 실물에서 도는지 확인하는 순서.

> 로직 전압 **3.3V** (UNO Q / STM32). 센서 전원은 **3V3 핀**에서 뽑는다. 5V 금지.

## 1. 배선표

| 부품 | 부품 핀 | UNO Q 핀 | 비고 |
|------|---------|----------|------|
| DHT11 (온습도) | VCC / `+` | **3V3** | 3.3V |
| | DATA / `S` | **D6** | 모듈형은 보통 내장 풀업 있음. 생센서면 DATA–VCC 사이 10kΩ 풀업 |
| | GND / `−` | **GND** | |
| 포토센서(CDS)+10kΩ | 전압분배 가운데 | **A2** | CDS 한쪽 3V3, 다른쪽이 10kΩ과 만나는 지점 → A2, 10kΩ 반대쪽 GND |
| 부저 모듈 | `S` / `I/O` | **D8** | |
| | `+` / VCC | **3V3** | 핀 2개짜리면 생략 |
| | `−` / GND | **GND** | |

```
DHT11      3V3 ─ VCC
           D6  ─ DATA
           GND ─ GND
포토센서   3V3 ─[CDS]─┬─ A2
                      └─[10kΩ]─ GND
부저       D8  ─ S,  3V3 ─ +,  GND ─ −
```

## 2. 소프트웨어 준비

1. App Lab(보드에 기본 설치)에서 이 레포의 `app/` 폴더를 연다.
2. 스케치가 **"DHT sensor library"(Adafruit)**를 쓴다. 라이브러리 매니저에서 설치.
   - ⚠️ UNO Q(STM32 코어)에서 컴파일 안 되면 → `DHT11`(Dhruba/Adafruit 대안) 등으로 교체 검토.
3. 빌드·배포 → 스케치(STM32)와 파이썬(리눅스)이 함께 올라간다.

## 3. 브링업 체크 순서 (이 순서대로)

**① 통신 살아있나**
- 배포 후 파이썬 로그에 2초마다 아래가 뜨면 정상:
  ```
  [IDLE] hum=52.0% temp=24.0C light=140 buzzer=0
  ```
- 아무것도 안 뜸 → 빌드/배포 실패 or Bridge 연결 문제 (센서 배선 아님).

**② DHT11 읽히나**
- `hum`, `temp`에 숫자가 나오면 OK.
- 로그에 `[DHT ERROR ...]`가 반복되면 → **DHT11 배선 문제** (D6 연결, 3V3 전원, 풀업 확인).
  이때 `조도(A2)=...` 값이 같이 뜨면 "보드·조도는 정상, DHT만 실패"로 좁혀진다.

**③ 포토센서 반응하나**
- 손으로 센서를 가리면 `light` 값이 크게 바뀌는지 본다 (밝으면 ↑/어두우면 ↓, 배선 방향에 따라 반대일 수 있음).
- 불 켜짐 임계값(기본 500)은 이 값들을 보고 나중에 보정.

**④ 부저 울리나**
- `VENT_SELFTEST=1`로 실행하면 **시작 직후 약 2초간 "삑"** 울린다 → 부저 배선 확인용.
  ```
  VENT_SELFTEST=1 python3 app/python/main.py   # (환경에 맞게 App Lab 실행 옵션으로)
  ```
- 안 울리면 → D8 연결, 부저 극성(`+`/`−`), 전원 확인.

## 4. 측정 모드

- **일반(알림 켬)**: 그냥 실행.
- **기준선(알림 끔, 기록만)**: `VENT_BASELINE=1` — 11주차 기준선 측정용.
- **CSV 경로 지정**: `VENT_LOG=/경로/vent_log.csv` (지정 안 하면 실행 폴더에 `vent_log.csv`).

## 5. 자주 나는 문제

| 증상 | 원인 후보 | 조치 |
|------|-----------|------|
| 로그가 아예 없음 | 빌드/배포 실패, Bridge 미연결 | App Lab 재배포, 스케치 컴파일 로그 확인 |
| `[DHT ERROR]` 반복 | DHT11 배선·전원·풀업 | D6/3V3/GND 재확인, 모듈 교체 |
| 컴파일 에러(DHT.h) | STM32 코어 비호환 | 다른 DHT 라이브러리로 교체 |
| 부저 무음 | D8 미연결, 극성, 전원 | `VENT_SELFTEST=1`로 재확인 |
| light 값 안 변함 | 포토센서 전압분배 배선 | CDS·10kΩ·A2 결선 확인 |
